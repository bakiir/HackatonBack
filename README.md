# Описание проекта

Этот проект представляет собой бэкэнд-приложение на Flask для комплексного управления и составления расписания экзаменов в учебном заведении.

**Основные возможности:**
- **Управление пользователями:** Регистрация и аутентификация пользователей (администраторов, студентов) с использованием JWT.
- **Инициализация сессии:** Загрузка исходных данных (списки экзаменов, аудиторий, факультетов) для создания новой сессии расписания.
- **Гибкое управление:** Возможность для администраторов факультетов управлять своими предметами (удалять, изменять статусы) до финальной генерации.
- **Автоматическое составление расписания:** Сложный алгоритм, который распределяет экзамены по датам, времени и аудиториям, минимизируя конфликты у студентов и преподавателей.
- **Управление конфликтами:** Инструменты для обнаружения и разрешения конфликтов в уже созданном расписании.
- **Назначение прокторов:** Автоматическое назначение наблюдателей (прокторов) на экзамены.
- **Экспорт:** Выгрузка общего расписания, расписания для студента или по секциям в формате Excel.

## `app.py` - API Сервер (Flask)

Это главный файл приложения, который запускает веб-сервер и определяет все HTTP маршруты (endpoints) для взаимодействия с системой.

### Вспомогательные функции

- `handle_nan_values(obj)`: Рекурсивно обрабатывает объект (словарь, список, DataFrame), заменяя значения `NaN` на `None`.
- `send_emails_to_admins()`: (Микросервисный подход) Отправляет email-уведомления администраторам через отдельный почтовый сервис. Запускается в фоновом потоке.
- `convert_numpy_types(obj)`: Рекурсивно преобразует типы данных NumPy (например, `np.int64`) в стандартные типы Python (например, `int`).

### Аутентификация и Управление пользователями

- **POST `/api/register`**
  - **Описание:** Регистрирует нового пользователя (по умолчанию - студента).
  - **Тело запроса (JSON):** `{ "email": "...", "password": "...", "full_name": "..." }`
  - **Ответ:** `201 CREATED` в случае успеха. `400 Bad Request` если данные неверны.

- **POST `/api/register-admin`**
  - **Описание:** Регистрирует нового администратора с определенной ролью.
  - **Аутентификация:** Требуется токен `admin`.
  - **Тело запроса (JSON):** `{ "email": "...", "password": "...", "full_name": "...", "role": "..." }`
  - **Ответ:** `201 CREATED` в случае успеха. `400 Bad Request` если роль недопустима.

- **POST `/api/login`**
  - **Описание:** Аутентифицирует пользователя и возвращает JWT токен.
  - **Тело запроса (JSON):** `{ "email": "...", "password": "..." }`
  - **Ответ:** `200 OK` с токеном доступа. `401 Unauthorized` при неверных данных.

- **PUT `/api/update-user/<user_id>`**
  - **Описание:** Обновляет данные пользователя.
  - **Аутентификация:** Требуется токен `admin`.
  - **Тело запроса (JSON):** `{ "email": "...", "full_name": "...", "role": "..." }` (все поля опциональны).
  - **Ответ:** `200 OK` в случае успеха.

- **DELETE `/api/delete-user/<user_id>`**
  - **Описание:** Удаляет пользователя.
  - **Аутентификация:** Требуется токен `admin`.
  - **Ответ:** `200 OK` в случае успеха. `404 Not Found` если пользователь не найден.

- **GET `/api/protected`**
  - **Описание:** Тестовый маршрут для проверки валидности JWT токена.
  - **Аутентификация:** Требуется любой валидный токен.

### Инициализация и Управление Расписанием (Draft)

- **POST `/api/init`**
  - **Описание:** Главный маршрут для инициализации новой сессии расписания. Загружает файлы, создает объект `ExamScheduler` и черновик сессии в БД.
  - **Аутентификация:** Требуется токен `admin`.
  - **Тело запроса:** `multipart/form-data` с файлами `exams`, `rooms`, `faculties` и полями `title`, `start_date`, `num_days`.
  - **Ответ:** `200 OK` со списком уникальных предметов и дат для дальнейшего управления.

- **POST `/api/manage_dates`**
  - **Описание:** Позволяет главному администратору управлять списком дат для экзаменов (удалять, добавлять, восстанавливать по умолчанию).
  - **Аутентификация:** Требуется токен `admin`.
  - **Тело запроса (JSON):** `{ "action": "remove" | "add_custom" | "restore", "date": "..." }`
  - **Ответ:** `200 OK` с обновленным списком дат.

- **POST `/api/manage`**
  - **Описание:** Многофункциональный маршрут для управления черновиком расписания администраторами факультетов.
  - **Аутентификация:** Требуется токен (роль проверяется внутри).
  - **Действия (`action`):**
    - `get_subjects`: Получает список предметов для факультета, определенного по роли пользователя.
    - `delete_subject`: Удаляет все секции, связанные с предметом.
    - `delete_section`: Удаляет конкретную секцию.
    - `generate`: Запускает финальную генерацию расписания. **Доступно только для `admin`** и только когда все остальные администраторы подтвердили готовность.
  - **Ответ:** Зависит от действия.

- **POST `/api/set_admin_status_draft`**
  - **Описание:** Позволяет администратору факультета установить статус "готов" (`ready`) для текущего черновика сессии.
  - **Аутентификация:** Требуется токен администратора факультета.
  - **Ответ:** `200 OK`.

- **GET `/api/check_all_drafts`**
  - **Описание:** Проверяет, все ли администраторы факультетов установили статус "готов".
  - **Аутентификация:** Требуется токен `admin`.
  - **Ответ:** `200 OK` с `{ "have_drafts": true/false }`.

- **GET `/api/admin_statuses`**
  - **Описание:** Возвращает текущие статусы всех администраторов для активного черновика.
  - **Аутентификация:** Требуется токен.
  - **Ответ:** `200 OK` со списком статусов.

- **POST `/api/update_exam_status` / `update_proctor_status` / `update_room_requirement` / `exams/batch-update`**
  - **Описание:** Маршруты для пакетного обновления свойств экзаменов в черновике (нужен ли экзамен, проктор, две аудитории и т.д.).
  - **Аутентификация:** Требуется токен.
  - **Тело запроса (JSON):** Массив объектов, каждый для одной секции. `[{ "section_id": "...", "has_exam": true/false, ... }]`

### Управление Аудиториями

- **GET `/api/classroom/107/free-slots`**
  - **Описание:** Получает список всех свободных слотов для аудитории 107.
  - **Ответ:** `200 OK` со списком слотов.

- **POST `/api/slots/book`**
  - **Описание:** Позволяет вручную забронировать слот в аудитории (в основном для 107).
  - **Тело запроса (JSON):** `{ "slot_id": "...", "subject": "...", "sections": [...] }`
  - **Ответ:** `200 OK` с результатом бронирования.

### Прокторы

- **POST `/api/proctors/assign`**
  - **Описание:** Загружает Excel файл со списком "нежелательных" прокторов и запускает процесс автоматического назначения.
  - **Аутентификация:** Требуется токен `admin`.
  - **Тело запроса:** `multipart/form-data` с файлом `proctors`.
  - **Ответ:** `200 OK`.

- **GET `/api/proctors/save_excel`**
  - **Описание:** Генерирует и сохраняет на сервере файл `proctors_list.xlsx` с результатами назначения прокторов.
  - **Ответ:** `200 OK`.

- **GET `/available-proctors/<date>/<time_slot>`**
  - **Описание:** Возвращает список прокторов, свободных в указанную дату и время.
  - **Ответ:** `200 OK` со списком имен.

### Управление Финальным Расписанием

- **GET `/api/sessions`**
  - **Описание:** Возвращает список всех созданных (не черновиков) сессий расписания.
  - **Аутентификация:** Требуется токен `admin`.

- **GET `/api/sessions/<session_id>`**
  - **Описание:** Получает детали конкретной сессии.
  - **Аутентификация:** Требуется токен `admin`.

- **POST `/api/sessions/<session_id>/activate`**
  - **Описание:** Делает выбранную сессию активной. Все последующие запросы будут работать с данными этой сессии.
  - **Аутентификация:** Требуется токен `admin`.

- **DELETE `/api/sessions/<session_id>`**
  - **Описание:** Удаляет сессию расписания.
  - **Аутентификация:** Требуется токен `admin`.

- **GET `/schedule`**
  - **Описание:** Возвращает полное сгенерированное расписание в формате JSON.

- **POST `/schedule/edit/<section>`**
  - **Описание:** Позволяет вручную отредактировать запись в расписании (изменить аудиторию, дату, время, проктора).
  - **Тело запроса (JSON):** `{ "room": "...", "date": "...", "time_slot": "...", "proctor": "..." }`

### Отчеты и Экспорт

- **GET `/schedule/stats`**
  - **Описание:** Возвращает статистику по последней генерации расписания (сколько всего, сколько запланировано, сколько не удалось).

- **GET `/api/schedule/status`**
  - **Описание:** Более детальный статус, включая список незапланированных секций.

- **GET `/schedule/export`**
  - **Описание:** Запускает генерацию и скачивание файла `general_schedule.xlsx` с общим расписанием.

- **GET `/api/report/conflicts`**
  - **Описание:** Возвращает отчет о конфликтах в текущем расписании.

- **GET `/section/<section_id>`**
  - **Описание:** Получает всю информацию по конкретной секции (студенты, расписание, преподаватель).

- **GET `/section/<section_id>/export`**
  - **Описание:** Экспортирует информацию по секции в Excel.

- **GET `/schedule/student/<student_id>`**
  - **Описание:** Получает персональное расписание для указанного студента.

- **GET `/schedule/student/<student_id>/export`**
  - **Описание:** Экспортирует персональное расписание студента в Excel.

## `services/exam_scheduler.py` - Ядро планировщика

Класс `ExamScheduler` является центральным компонентом, отвечающим за всю логику составления расписания.

### `ExamScheduler` class

#### `__init__(self, ...)`
- **Описание:** Конструктор класса. Инициализирует планировщик. Может работать в двух режимах:
  1. **Создание новой сессии:** Принимает пути к файлам (`exams_file`, `rooms_file`, `faculties_file`), дату начала и количество дней.
  2. **Загрузка существующей сессии:** Принимает объект `session_data` из базы данных и восстанавливает состояние планировщика.
- **Параметры:**
  - `title`: Название сессии.
  - `start_date`, `num_days`: Параметры для новой сессии.
  - `time_step`, `work_day_start`, `work_day_end`: Конфигурация временных слотов.

#### Основные публичные методы

- `create_schedule(self)`: **Главный метод.** Запускает весь процесс создания расписания. Сортирует группы, итеративно распределяет их по слотам, пытаясь минимизировать конфликты.
- `assign_proctors(self, proctors_path)`: Назначает прокторов на экзамены, учитывая их нагрузку, факультет и список исключений из файла.
- `assign_seats(self)`: Распределяет студентов по местам в назначенных аудиториях.
- `run_scheduling_process(self, skip_management)`: Оркестрирует процесс планирования (устаревший, логика перенесена в API).
- `optimize_schedule(self, student_exams)`: Запускает алгоритм "имитации отжига" для поиска лучшего решения и минимизации конфликтов в уже созданном расписании.
- `get_student_sections(self, student_id)`: Возвращает DataFrame с расписанием для конкретного студента.
- `get_section_info(self, section_id)`: Возвращает подробную информацию о секции, включая список студентов и их места.
- `get_by_faculty(self, faculty)`: Возвращает список предметов для указанного факультета.
- `get_unique_subjects(self)`: Возвращает отсортированный список всех уникальных предметов.
- `find_available_rooms(self, day, time_slot)`: Находит свободные аудитории в указанный день и время.
- `get_all_proctors(self)`: Возвращает полный список всех прокторов.

#### Методы обновления данных

- `update_exam_status(self, section_id, has_exam)`: Помечает, нужно ли проводить экзамен для секции.
- `update_exam_durations(self, exam_data)`: Массово обновляет длительность экзаменов.
- `update_room_requirement(self, section_id, two_rooms_needed)`: Устанавливает, требуются ли для секции две аудитории.
- `batch_update_exams(self, exams_data)`: Пакетно обновляет статусы экзаменов (наличие, проктор, аудитории).
- `edit_schedule_entry(self, ...)`: Вручную изменяет запись в финальном расписании.

#### Методы управления датами

- `get_current_dates(self)`: Возвращает текущий список дат сессии.
- `remove_date(self, date_str)`: Удаляет дату из списка.
- `add_custom_date(self, date_str)`: Добавляет новую дату в список.
- `restore_default_dates(self)`: Восстанавливает даты по умолчанию.

#### Методы экспорта

- `export_schedule(self, output_excel)`: Экспортирует общее расписание в Excel.
- `export_html_schedule(self, output_html)`: Экспортирует общее расписание в HTML.
- `export_student_schedule_to_excel(self, student_id, output_file)`: Экспортирует расписание студента в Excel.
- `export_section_info_to_excel(self, section_info, output_file)`: Экспортирует информацию по секции в Excel.

#### Внутренние (приватные) методы

- `_prepare_data(self)`: Подготавливает и очищает данные после загрузки из файлов.
- `_load_from_session(self, session_data)`: Загружает состояние из объекта сессии БД.
- `_generate_initial_dates(self)`: Генерирует список дат на основе даты начала и длительности.
- `_schedule_large_groups_in_107(self, ...)`: Реализует логику приоритетного планирования больших групп в аудиторию 107.
- `_load_manual_bookings(self)`: Загружает экзамены, забронированные вручную через API.
- `_is_instructor_available(self, ...)`: Проверяет, свободен ли преподаватель в указанное время.
- `_delete_sections(self, sections)`: Удаляет секции из всех внутренних DataFrame.
- `_log_schedule_stats(self)`: Логирует статистику по созданному расписанию.
